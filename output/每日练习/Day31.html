Day 31 · What 感叹句：一个人或物

姓名：____________ 日期：____________ 用时：______

感叹句表达“多么……啊”，不是在提问。单数可数名词常用 What a / an + 形容词 + 名词 + 主语 + be!；a / an 看后面紧跟词的开头音。

例子：It is a nice day. → What a nice day it is!

A 今日练习

1. 填 a / an：What ___ nice book it is!
2. 填 a / an：What ___ interesting book it is!
3. 填 a / an：What ___ useful book it is!
4. 用 What 改为完整感叹句：It is a big dog.
5. 用 What 改为完整感叹句：It is an old bike.
6. 用 What 改为完整感叹句：She is a kind girl.
7. 用 What 改为完整感叹句：He is a tall boy.
8. 连词成句：a / what / day / lovely / it / is / !
9. 改正错误：What a nice bag is it!
10. 在句末填 ? 或 !：What a beautiful flower it is___

B 订正后换句再试

1. 用 What 改为完整感叹句：It is a small cat.
2. 用 What 改为完整感叹句：It is an interesting story.

C 旧题复练

1. 对画线部分提问：Ben is eleven.
2. 改正错误：How many book does Lucy have?

A 区：独立对 ___ / 10；看提示对 ___；待订正 ___。
订正：说意思 → 找主语 → 选结构 → 完整重写 → 换句再试。
